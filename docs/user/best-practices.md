# Best Practices

This chapter consolidates best practices from every module into daily, weekly, and monthly checklists — plus an overall recommended workflow.

---

## Daily Checklist

### Opening

- [ ] Count the physical cash in your drawer
- [ ] Open a shift with the correct opening cash amount
- [ ] Check the Dashboard for priority alerts
- [ ] Review Today's Briefing
- [ ] Check low stock items
- [ ] Review pending services from yesterday

### Throughout the Day

- [ ] Create service orders for every walk-in customer
- [ ] Log spare parts immediately when used in repairs
- [ ] Process payments when customers pay
- [ ] Record manual cash in/out as they happen
- [ ] Update service statuses promptly
- [ ] Assign technicians to new services
- [ ] Perform QC before marking as "Ready for Pickup"
- [ ] Hand over completed devices to customers

### Closing

- [ ] Count the physical cash in your drawer
- [ ] Verify expected cash against actual cash
- [ ] Document any differences with clear notes
- [ ] Close the shift
- [ ] Review the shift report (auto-generated PDF)
- [ ] Ensure all services are in proper status (no incomplete items left open)

---

## Weekly Checklist

### Management

- [ ] Review weekly revenue report
- [ ] Compare week-over-week performance
- [ ] Check technician workload balance
- [ ] Review inventory — what needs to be reordered
- [ ] Identify slow-moving stock
- [ ] Review pending services — any that are stuck?
- [ ] Check customer satisfaction trends
- [ ] Review cash difference reports for all shifts

### Inventory

- [ ] Perform spot checks on high-value items
- [ ] Review low stock alerts and place orders
- [ ] Verify incoming purchase orders
- [ ] Check for expired or damaged items
- [ ] Review stock transfer requests between branches

### Staff

- [ ] Hold a brief team meeting to discuss issues
- [ ] Recognize top-performing technicians
- [ ] Address any workflow bottlenecks
- [ ] Review any training needs

---

## Monthly Checklist

### Financial Review

- [ ] Generate monthly revenue report
- [ ] Generate monthly profit and loss report
- [ ] Compare actual revenue to forecast
- [ ] Review all expenses by category
- [ ] Reconcile cash across all shifts
- [ ] Review tax calculations
- [ ] Check that all invoices and receipts are accounted for

### Inventory Review

- [ ] Full physical inventory count (at least for high-value items)
- [ ] Reconcile physical count with system records
- [ ] Make stock adjustments as needed
- [ ] Review supplier performance (delivery times, prices)
- [ ] Identify obsolete stock for discount or write-off

### Performance Review

- [ ] Branch performance comparison
- [ ] Technician performance review
- [ ] Service completion rate
- [ ] Average repair time
- [ ] Customer return rate
- [ ] SLA compliance

### System Maintenance

- [ ] Review user accounts — disable any that are no longer needed
- [ ] Verify backup is running correctly
- [ ] Check notification settings
- [ ] Review activity log for unusual actions
- [ ] Update any system settings as needed

## Recommended Workflow

### For Shop Owners

```
Daily:   Dashboard review → Priority alerts → Revenue check
Weekly:  Financial summary → Branch comparison → Team meeting
Monthly: Full P&L → Inventory audit → Performance reviews
```

### For Branch Managers

```
Daily:
  1. Open shift (or verify it's open)
  2. Check Dashboard for alerts
  3. Review pending services
  4. Assign technicians
  5. Monitor workflow throughout the day
  6. Close shift with proper cash handling
  7. Review shift report

Weekly:
  1. Review team performance
  2. Check inventory levels
  3. Place stock orders
  4. Review customer feedback

Monthly:
  1. Full inventory count
  2. Complete financial review
  3. Staff performance evaluation
```

### For Frontliners / Cashiers

```
Daily:
  1. Open shift with accurate opening cash
  2. Greet customers and create service orders
  3. Process POS sales
  4. Handle payments
  5. Record cash in/out
  6. Hand over completed devices
  7. Close shift with accurate closing cash
```

### For Technicians

```
Daily:
  1. Check assigned services
  2. Start diagnosis on new services
  3. Order parts if needed
  4. Perform repairs
  5. Log parts used
  6. Send to QC when complete
  7. Update status for every step
```

## Housekeeping Rules

| Rule | Why |
|------|-----|
| Every cash movement must be recorded | Prevents discrepancies at closing |
| Every service must have a customer record | Required for history and warranty |
| Every part used must be logged | Keeps inventory accurate |
| Every status change should have a note | Provides context for the timeline |
| Every shift must be opened before transactions | Ensures cash accountability |
| Every shift must be closed at end of day | Prevents data mixing between days |
| Receipts should be given to every customer | Professionalism and record keeping |

## Efficiency Tips

- **Use keyboard shortcuts** — Ctrl+K (Cmd+K) for AI command palette, Tab to move between fields
- **Barcode scanners** — Speed up POS and inventory by using scanners
- **Kanban view** — Great for managers to see workflow at a glance
- **Batch processing** — When logging parts, do multiple services at once if you have downtime
- **Communication** — Use service notes to communicate between frontliners and technicians
- **Templates** — For common repairs, create standard service templates if available

## Common Pitfalls to Avoid

| Pitfall | How to Avoid |
|---------|-------------|
| Not opening a shift | Check Dynamic Island before any transaction |
| Delayed part logging | Log immediately; memory is unreliable |
| Skipping QC | Always quality-check before handover |
| Wrong status updates | Follow the status flow in order |
| Ignoring small cash differences | Small issues compound over time |
| Not using notes | Future-you will thank past-you for notes |
| Overlooking technician workload | Check workload before assigning |
| No backup plan | Ensure someone can cover for absences |

## Final Advice

> **"Seervisio is only as good as the data you put in."**

If you enter data accurately and promptly, the system will give you accurate and timely information. The reports, insights, and recommendations all depend on the quality of your data entry.

**Train your team.** Make sure everyone understands why each step matters. When a technician understands that logging parts correctly protects inventory accuracy, they're more likely to do it consistently.

**Review and improve.** Use the reports to identify areas for improvement. Share findings with your team. Celebrate wins and address challenges together.

**Stay consistent.** Follow the checklists. They're designed to catch common mistakes and ensure nothing is missed.
