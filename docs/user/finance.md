# Finance Module

The Finance module tracks all money movements in your business — income, expenses, and cash flow.

---

## Overview

The Finance module is divided into several sections:

| Section | Purpose |
|---------|---------|
| **Income** | Record money coming in (other than service/POS payments) |
| **Expense** | Record money going out (operational costs, purchases) |
| **Transactions** | View all financial movements in one place |
| **Summary** | See totals for revenue, expenses, and profit |
| **Reports** | Generate financial reports |

---

## Income

### What Counts as Income?

- Manual cash added to the drawer (e.g., petty cash top-up)
- Other income not from services or POS
- Transfer from another account

### Recording Income

1. Go to **Finance** → **Income**
2. Click **Tambah Pemasukan**
3. Fill in the details:

| Field | Description |
|-------|-------------|
| **Branch** | Which branch this income belongs to |
| **Account** | Which cash/bank account receives it |
| **Category** | Type of income |
| **Amount** | Amount in Rupiah |
| **Description** | What this income is for |
| **Date** | Date of the transaction |

4. Click **Simpan**

### Common Income Categories

| Category | Example |
|----------|---------|
| Other Services | Revenue from non-repair services |
| Product Sales | Accessory sales (if not through POS) |
| Deposit Refund | Refunding a customer deposit |
| Other | Any other income |

---

## Expense

### What Counts as an Expense?

- Rent, utilities, salaries
- Office supplies
- Marketing costs
- Operational expenses

### Recording an Expense

1. Go to **Finance** → **Expense**
2. Click **Catat Pengeluaran**
3. Fill in the details:

| Field | Description |
|-------|-------------|
| **Branch** | Which branch this expense belongs to |
| **Account** | Which account it comes from |
| **Category** | Type of expense |
| **Amount** | Amount in Rupiah |
| **Description** | What this expense is for |
| **Date** | Date of the transaction |

4. Click **Simpan**

### Common Expense Categories

| Category | Example |
|----------|---------|
| Rent | Monthly store rent |
| Utilities | Electricity, water, internet |
| Salary | Staff wages |
| Supplies | Office consumables |
| Marketing | Ads, promotions |
| Maintenance | Store equipment repair |
| Transportation | Delivery, travel costs |

## Transactions

### Viewing All Transactions

The transactions view shows every financial movement in chronological order:

- Income entries
- Expense entries
- POS payments
- Service payments
- Stock purchases

### Filtering

You can filter by:

| Filter | Description |
|--------|-------------|
| Branch | Show transactions for a specific branch |
| Account | Filter by payment account |
| Type | Income only, Expense only, or All |
| Date Range | Custom start and end dates |
| Source | Manual, POS, Service, Expense |
| Search | Find by description or amount |

### Exporting

You can export the transaction list to:
- **PDF** — For printing or sharing
- **Excel/CSV** — For analysis in spreadsheet software

## Reports

### Daily Summary

Shows a quick snapshot of today's finances:

- Total income today
- Total expenses today
- Net cash flow
- Number of transactions

### Profit Report

Shows your profit over a selected period:

| Metric | What It Shows |
|--------|---------------|
| **Total Revenue** | All money received |
| **Total Expenses** | All money spent |
| **Net Profit** | Revenue minus expenses |
| **Profit Margin** | Profit as percentage of revenue |

### Cash Flow Report

Shows the movement of cash in and out over time:
- Visual chart of daily/weekly cash flow
- Compare income vs expenses
- Identify trends

---

## Profit Calculation

### How Profit is Calculated

Profit = Total Revenue − Total Expenses

**Revenue includes:**
- Service fees collected
- POS product sales
- Other income recorded

**Expenses include:**
- Operating expenses recorded
- Stock purchases
- Parts used in services (COGS)
- Other expenses

> **Note:** The profit shown in Finance is an estimate. For accurate profit, consider all costs including salaries, rent, and overhead.

## Best Practices

- **Record expenses immediately** — Don't wait until end of day
- **Categorize correctly** — Proper categories make reporting useful
- **Reconcile daily** — Compare system records with actual cash
- **Attach receipts** — If available, attach receipt images to transactions
- **Use notes** — Always describe what each transaction is for

### Common Mistakes

| Mistake | Consequence | Prevention |
|---------|-------------|------------|
| Forgetting to record expense | Profit looks higher than reality | Record as soon as you pay |
| Wrong category | Reports become misleading | Double-check the category |
| Not linking to branch | Can't analyze per-branch profit | Always select the correct branch |
| Duplicate entries | Inflated expenses | Review before saving |
| Not reconciling | Hidden discrepancies | Reconcile cash daily |
