# Reports

The Reports module helps you analyze your business performance with detailed data and visualizations.

---

## Revenue Report

### What It Shows

- Total revenue for the selected period
- Breakdown by source (Service, POS, Other)
- Daily/weekly/monthly trends
- Comparison to previous periods

### How to Use

1. Go to **Reports** → **Revenue**
2. Select the period (Today, This Week, This Month, Custom)
3. Select the branch (All or specific)
4. View the data

### What to Look For

- **Trend** — Is revenue growing or declining?
- **Peak days** — Which days are busiest?
- **Revenue sources** — Which brings more: services or product sales?
- **Comparison** — How does this period compare to last?

## Services Report

### What It Shows

- Total services created
- Services by status (completed, pending, cancelled)
- Average completion time
- Technician performance
- Most common repair types

### How to Use

1. Go to **Reports** → **Services**
2. Filter by date range, branch, technician, or status
3. View the data

### What to Look For

- **Backlog** — Are services piling up at any stage?
- **Technician performance** — Who completes the most? Who takes longest?
- **Common repairs** — What do customers need most? Stock those parts.
- **SLA compliance** — Are services completed on time?

## Inventory Report

### What It Shows

- Current stock levels
- Low stock items
- Stock movement history
- Most used parts
- Inventory value

### How to Use

1. Go to **Reports** → **Inventory**
2. Filter by category, product, or date range
3. View the data

### What to Look For

- **Fast-moving items** — Which parts are used most?

## Performance Report

### What It Shows

- Technician productivity metrics
- Service completion rates
- Average repair time
- Customer satisfaction scores
- Branch comparison

### How to Use

1. Go to **Reports** → **Performance**
2. Select the period and branch
3. View the data

### Key Metrics

| Metric | Description |
|--------|-------------|
| **Services Completed** | Total finished services |
| **Avg Completion Time** | Average time from creation to completion |
| **First-Time Fix Rate** | % of repairs completed correctly on first attempt |
| **Customer Rating** | Average rating from customer feedback |

## Technician Report

### What It Shows

Performance data for each technician:

| Metric | Description |
|--------|-------------|
| **Services Assigned** | Total services assigned to this technician |
| **Services Completed** | Services they finished |
| **Pending Services** | Services still in progress |
| **Average Time** | How long they take per repair |
| **Parts Used** | Total value of parts they consumed |

### How to Use

1. Go to **Reports** → **Technicians**
2. Select a technician or view all
3. Select the period

### What to Look For

- **Workload balance** — Is one tech overloaded while others are idle?
- **Efficiency** — Who completes repairs fastest?
- **Quality** — Who has the most rework or warranty returns?

## Branch Report

### What It Shows

Compare performance across branches:

| Metric | Branch A | Branch B | Branch C |
|--------|:--------:|:--------:|:--------:|
| Revenue | ✅ | ✅ | ✅ |
| Services | ✅ | ✅ | ✅ |
| Expenses | ✅ | ✅ | ✅ |
| Profit | ✅ | ✅ | ✅ |
| Technicians | ✅ | ✅ | ✅ |

### How to Use

1. Go to **Reports** → **Branches**
2. Select the period
3. View the comparison table

### What to Look For

- **Best performer** — Which branch is doing best?
- **Underperformer** — Which branch needs support?
- **Opportunities** — Can best practices be shared?
- **Resource allocation** — Do all branches have what they need?

## Exporting Reports

### Available Formats

| Format | Use When |
|--------|----------|
| **PDF** | Sharing with management, printing |
| **Excel / CSV** | Further analysis, data manipulation |

### How to Export

1. Open the report you want
2. Click **Export** or **Download**
3. Select the format
4. The file downloads to your computer

## Scheduling Reports

You can schedule regular reports to be sent to your email:

1. Go to **Reports** → **Scheduled Reports**
2. Click **Buat Jadwal**
3. Select the report type
4. Set the frequency (Daily, Weekly, Monthly)
5. Enter recipient email addresses
6. Click **Simpan**

## Best Practices

- **Review reports daily** — At least check the Daily Summary
- **Compare week over week** — Spot trends early
- **Share with your team** — Use reports for morning briefings
- **Export for records** — Keep monthly reports for tax purposes
- **Use filters** — Get specific answers by filtering the right data

### Common Mistakes

| Mistake | Prevention |
|---------|------------|
| Comparing different periods | Always compare like-for-like (e.g., this Monday vs last Monday) |
| Ignoring trends | One day's data is noisy — look at trends over time |
| Not filtering by branch | Branch data gets mixed up in "All Branches" view |
| Forgetting to export | Schedule reports to be sent automatically |
